Data flow (request lifecycle)
1
User action in React (browser)
User clicks "Analyze Resume". React sends POST /api/resume/analyze with Authorization: Bearer <accessToken> and FormData (PDF file).
2
Express middleware chain
Request hits Express → cors() → express.json() → authMiddleware (verifies JWT, attaches req.user) → Multer (handles file upload to /tmp).
3
Route handler (controller)
resumeController.analyze() extracts text from PDF using pdf-parse, builds a structured prompt, calls geminiService.generateContent().
4
Gemini API call
geminiService sends the prompt to gemini-1.5-flash model. Receives structured JSON response with ATS score, keyword gaps, and suggestions.
5
MongoDB save
Result saved to resumes collection via Mongoose. Resume.create({ userId, atsScore, suggestions, analysisDate }).
6
JSON response to React
Express sends { success: true, data: { atsScore, suggestions, keywords } }. React updates state, renders the results card. Total time: ~8–15 seconds.

SDK SetupUse @google/generative-ai npm package. Gemini 1.5 Flash is free: 15 requests/minute, 1 million tokens/day. More than enough for a student project.
geminiService.js — central AI file
const { GoogleGenerativeAI } = require('@google/generative-ai'); const genAI = new GoogleGenerativeAI(process.env.GEMINI_API_KEY); const model = genAI.getGenerativeModel({ model: 'gemini-1.5-flash' }); // 1. ATS Resume Analysis async function analyzeResume(resumeText, jobDescription) { const prompt = `You are an expert ATS system. Analyze the resume below and return ONLY a JSON object with this exact structure (no markdown): { "atsScore": number (0-100), "breakdown": { "formatting": number, "keywords": number, "impact": number }, "suggestions": [string, string, string], "keywordGaps": [string, string] } Resume: ${resumeText} ${jobDescription ? "Job Description: " + jobDescription : ""}`; const result = await model.generateContent(prompt); return JSON.parse(result.response.text()); } // 2. Mock Interview — get first question async function startInterview(role, type) { const prompt = `Generate the first interview question for a ${role} ${type} interview. Return JSON: { "question": string, "hint": string }`; const r = await model.generateContent(prompt); return JSON.parse(r.response.text()); } // 3. Evaluate answer + generate next question async function evaluateAnswer(question, answer, role, isLast) { const prompt = `Question: "${question}" Answer: "${answer}" Evaluate and return JSON: { "score": number, "feedback": string, "modelAnswer": string, ${!isLast ? '"nextQuestion": string,' : ''} "isComplete": ${isLast} }`; const r = await model.generateContent(prompt); return JSON.parse(r.response.text()); } // 4. Career roadmap generation async function generateRoadmap(targetRole, skills, availableHours) { const prompt = `Create a 12-week study plan for "${targetRole}". Current skills: ${skills.join(', ')}. Hours/week available: ${availableHours}. Return JSON: { "weeks": [{ "week": number, "focus": string, "tasks": [string], "resources": [string] }] }`; const r = await model.generateContent(prompt); return JSON.parse(r.response.text()); } module.exports = { analyzeResume, startInterview, evaluateAnswer, generateRoadmap };
5 AI Features mapped to Gemini calls
ATS Scoring
analyzeResume(text, jd) → JSON with score, breakdown, suggestions. Prompt enforces JSON-only output.
Mock Interview
startInterview() → first Q. evaluateAnswer() per turn → score + next Q. 10-question session.
Roadmap
generateRoadmap(role, skills, hours) → 12-week JSON plan with tasks and resource links.
Question Generator
Generate topic-specific technical or HR questions on demand. Falls back to DB seed questions.
Progress Insight
Send aggregated stats to Gemini, receive a 3-sentence plain-English progress summary for dashboard.
Rate limit protectionWrap every Gemini call in try/catch. If you hit 15 RPM, return a 429 with "Please wait a moment" message. Add a simple in-memory request timestamp array to enforce max 12 calls/min from your backend side, leaving headroom.
Token strategy
Access Token15 min
Short-lived JWT. Stored in memory (Zustand). Contains userId, email, role. Sent as Bearer header.
Refresh Token7 days
Long-lived JWT. Stored in httpOnly cookie. Hashed copy saved in User.refreshToken field in DB.
authMiddlewareEvery route
Extracts Bearer token, verifies with jwt.verify(), attaches decoded payload to req.user. Throws 401 on failure.
Register → Verify → Login flow
1
POST /auth/register
Hash password with bcrypt (cost 10). Generate 6-digit OTP. Save user with isVerified: false. Send OTP via Nodemailer to email. Return 201.
2
POST /auth/verify-otp
Compare OTP, check expiry (10 min). Set isVerified: true, clear OTP fields. Return 200.
3
POST /auth/login
Find user by email. bcrypt.compare(password, hash). Generate accessToken (15 min) + refreshToken (7 days). Hash refreshToken, save to DB. Set refreshToken in httpOnly cookie. Return accessToken in body.
4
React stores accessToken in Zustand (memory only)
Never localStorage. On page reload, silently call /auth/refresh using the cookie. If valid, get new accessToken. Axios request interceptor adds Authorization header automatically.
5
Axios response interceptor handles 401
If API returns 401, automatically call /auth/refresh. If refresh succeeds, retry original request. If refresh fails (expired/revoked), redirect to /login. User never sees raw errors.
auth.js middleware
const jwt = require('jsonwebtoken'); const authMiddleware = (req, res, next) => { const authHeader = req.headers.authorization; if (!authHeader?.startsWith('Bearer ')) return res.status(401).json({ message: 'No token' }); const token = authHeader.split(' ')[1]; try { req.user = jwt.verify(token, process.env.JWT_SECRET); next(); } catch { res.status(401).json({ message: 'Invalid or expired token' }); } }; module.exports = authMiddleware;

Deploy backend to Render, frontend to Vercel, verify CORS and cookies

Things to skip for V1 (add later)
WebSockets / Socket.io — not needed, polling or TanStack Query refetch is fine
File storage (S3/Cloudinary) — save resume raw text to MongoDB, skip storing PDF files
OAuth / Google Login — email + OTP is sufficient; add OAuth in V2
Redis cache — MongoDB Atlas has enough performance for <1000 users
Video interview / webcam — complex; AI text interview is the MVP
Payment gateway / subscriptions — launch free, monetise in V2
Docker / containerisation — overkill for a solo dev on Render free tier
